Mzamo Child Guidance & Training Initiative of KZN

Information and Donor Engagement System

Project Overview

This is a comprehensive information and donor engagement system developed for Mzamo Child Guidance & Training Initiative of KZN, a community development organisation established in January 1981 that provides support to children with disabilities and their families.

The system consists of:
- A public-facing website providing information about the organisation, its services, and activities
- An administration portal allowing authorised staff to manage organisational information, programmes, news, reports, and enquiries

### System Features

#### Public Website
- Home page with organisation overview and statistics
- About Us page with history and mission
- Services page listing all programmes
- News & Updates page
- Contact page with enquiry form
- WhatsApp chat integration

Administration Portal
- Secure login system
- Dashboard with real-time statistics
- Manage Programmes & Services (Add, Edit, Delete, Toggle Status)
- Manage News Articles (Add, Edit, Delete, Toggle Status)
- Manage Reports & Documents (Upload, Download, Edit, Delete)
- Manage Enquiries (View, Update Status, Delete)
